About RN Laravel API Runner

One place to run the mobile stack

Runner starts your Laravel API and Expo app together, connects them through your selected LAN address, and shows the Expo link as a QR code.

What it solves

Before Runner, you had to open two terminals, start Laravel and Expo separately, and keep the mobile API URL in sync with your computer’s Wi-Fi address. When that address changed, the phone could point at the wrong API.

Runner reads the selected network address and service ports, then passes the matching API URL to Expo each time it starts. You do not need to edit either project’s .env file for a network change. If Wi-Fi changes while services run, stop and start them again.

How the connection works

  1. Runner starts Laravel on the configured API port, reachable from your LAN.
  2. Runner starts the Expo CLI installed in your mobile project and gives that process EXPO_PUBLIC_API_URL=http://LAN-address:API-port.
  3. Expo serves the app bundle. The phone reaches Laravel at that LAN URL.
  4. Your app keeps its own tenant or domain configuration. Runner overrides EXPO_PUBLIC_API_URL and REACT_NATIVE_PACKAGER_HOSTNAME only for the Expo process it starts.

Runner does not edit mobile or backend .env files. API URL is temporary process environment, scoped to Expo Runner launches.

Example Bash equivalent

Replace placeholder with your computer’s current LAN address. Use ports from Runner settings.

LAN_IP="<your-LAN-IP>"
API_PORT=8000
EXPO_PORT=8081
EXPO_PUBLIC_API_URL="http://$LAN_IP:$API_PORT" \
REACT_NATIVE_PACKAGER_HOSTNAME="$LAN_IP" \
npx expo start --lan --port "$EXPO_PORT" --dev-client

Run from the mobile project folder. Runner uses the project’s local Expo CLI and scopes these values to its Expo process.

Available now

  • Configure mobile/API folders, PHP executable, ports, runtime, and phone-reachable network address.
  • Check setup, start both services, or start/restart/stop each service separately.
  • Generate a development-build or Expo Go link and QR code.
  • View separate API/Expo consoles, pause or clear each, dock right or expand full screen.
  • Switch light/dark theme. Duplicate Runner launches open the active dashboard; busy dashboard ports use a nearby free port.

Not supported yet

  • Choose a remote backend on another network. Runner currently connects Expo to the configured local Laravel API through your selected LAN.
  • Build, sign, or install an APK from this dashboard. Planned: run a configured Android build command from the mobile project’s package.json.
  • Start databases, queues, or Redis; run migrations; clear Laravel caches; or validate a full login and tenant flow.

API readiness currently means its port is listening. Phone access can still depend on Wi-Fi isolation, firewall rules, and matching tenant domains.
